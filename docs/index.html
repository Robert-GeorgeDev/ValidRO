ValidRO

 Steluță pe GitHub

Verifică un CNP, un CUI sau un IBAN, vezi ce înseamnă fiecare cifră și cum se calculează cifra de control.

Cum s-a calculat cifra de control
Rezultatul pentru dezvoltatori

Verificarea rulează în browserul tău. Nimic din ce scrii nu e trimis și nu rămâne salvat.

Pentru dezvoltatori

Aceleași verificări, ca bibliotecă TypeScript fără dependențe.

npm install validro
import { validateCnp } from "validro";

validateCnp("3000101221148");
// { valid: false, data: null,
//   error: "Cifra de control este greșită (așteptat 7)" }
  • CNP: dată reală (inclusiv ani bisecți), cod de județ, inclusiv codul 70 folosit pentru CNP-urile noi, cifra de control.
  • CUI / CIF: cu sau fără prefixul RO, cifra de control.
  • IBAN: structura românească de 24 de caractere și verificarea mod 97.

Un cod valid e corect ca formă; asta nu înseamnă că aparține cuiva. Exemplele de pe pagină sunt fictive.
