# Code of Conduct

ValidRO follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep discussions about the code. Harassment, insults and personal attacks are not tolerated.

This project handles personal identifiers, so one more rule applies here: never post anyone's real CNP, IBAN or other personal data in issues, discussions or pull requests.

To report unacceptable behaviour, contact the maintainer privately through the email address on their GitHub profile. Reports are handled confidentially.
